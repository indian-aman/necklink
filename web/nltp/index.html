01 // ALGEBRAIC LOSS HEALING

GF(2^8) Cauchy Reed-Solomon

Slices payloads into k = 8 shard generations over GF(2^8) (0x11D). Any 8 distinct systematic or Cauchy parity shards solve the generation via Gauss-Jordan elimination (956 MB/s branchless gf_axpy in C99; zero-GF(2^8) fast-path on clean links).

02 // EPHEMERAL FORWARD SECRECY

1-RTT X25519 + PSK Sessions

100-byte HELLO_ACK fits inside a single 250 B ESP-NOW v1 frame, derives directional ChaCha20-Poly1305 keys, wipes ephemeral scalars immediately, and guards a 512-packet RFC 6479 replay window across 10% packet reordering.

03 // BUILT-IN TELEMETRY CODEC

Zero-Dependency LZ4 + Auto-Bypass

Compresses JSONL/CSV/NMEA logs 4×–20× at 1,164 MB/s before FEC slicing, automatically bypasses incompressible JPEGs/ZIPs (0 B inflation), and performs zero-heap in-place decompression on C99/Arduino MCUs.

04 // OUT-OF-BAND CONTROL

Priority Reflex Lane (send_reflex)

Urgent actuator commands (STOP, RESET) bypass multi-megabyte transfers with zero head-of-line blocking, emit cryptic twins, and retransmit with exponential backoff until PT_REFLEX_ACK confirms single delivery.

05 // CROSS-CHIP RADIO MESH

ESP8266 (v1) ↔ ESP32 (v2)

ESP8266 (80 KB SRAM) sends 242 B encrypted v1 frames that any ESP32 hub decodes automatically alongside 1,010 B v2 frames, bypassing ESP-NOW's 6–17 encrypted peer hardware table cap via payload AEAD + LRU eviction.

06 // CELLULAR & WAN TRAVERSAL

STUN Punch + Zero-Key 4G Relay

Queries RFC 5389 STUN on the live socket, punches NATs via TTL=2 probes, supports 0-RTT Wi-Fi ↔ 5G roaming by authenticated conn_id, and falls back to a 1-port UDP NLTPRelayHub that holds zero keys.

05 // Honest Protocol Selection Guide

When to Use NLTP — and When Standard Protocols Win

NLTP is engineered specifically for lossy wireless, off-grid MCU, and CGNAT links. Here is where NLTP excels and where you should keep using MQTT, TCP BBR, or raw ESP-NOW.

Use NLTP v1.6.0 When:

  • Lossy RF, Cellular Edge, Marine, or Satellite Links (2–35% loss): Shipping binary sensor batches, JSONL/CSV logs, snapshots, or OTA firmware without TCP/MQTT retransmit stalls.
  • Routerless ESP32 / ESP8266 Meshes: You need multi-KB encrypted files over 2.4 GHz ESP-NOW, cross-chip v1 ↔ v2 interop, or unlimited encrypted sensor peers.
  • 4G/5G Carrier CGNAT Traversal: Connecting field gateways directly to Python, C99, Node.js, or Java without VPNs, TLS cert churn, or heavyweight cloud brokers.
  • NLTP + MQTT Together: Use NLTP on the lossy wireless first mile (Sensor → Gateway/Ingest) and fan verified payloads out to MQTT inside your cloud backend.

Stick With MQTT / TCP BBR / Raw ESP-NOW When:

  • Cloud Pub/Sub Topic Routing (a/+/c) on Clean Wi-Fi: Use MQTT — topic wildcards, retained state, and 1-to-10,000 subscriber fan-out are MQTT's purpose-built domain.
  • Clean Wired/Wi-Fi Server Transfers (>= 10 MB): Kernel TCP BBR and QUIC are 12–27% faster on uncompressed clean links and send fewer wire bytes (1.04× vs NLTP's 1.22–1.60× FEC overhead).
  • Coin-Cell <= 250 B Unconfirmed Sensor Pings: Raw ESP-NOW wakes and fires a single frame in ~1–3 ms with zero handshake state when occasional drops are acceptable.
Security & Safety Disclosure: Always generate keys via nltp gen-key (a weak passphrase hashed once with SHA-256 can be brute-forced offline). Ephemeral X25519 + PSK forward secrecy protects past recorded sessions if a PSK is later leaked, but any holder of an unrotated fleet PSK can authenticate new sessions until the key is rotated. NLTP's portable crypto implementations have not undergone an independent third-party cryptographic audit, and software Reflex commands must never be the sole safety interlock on physical machinery.
