Modules

Five standalone modules. One architecture.

Install only the module you need, or combine all five into a closed-loop reflex stack.

Cervical connective

NLTP pynltp

Loss-resilient UDP file, telemetry and reflex transport with GF(2^8) Cauchy FEC, ChaCha20-Poly1305 AEAD and single-port 4G CGNAT traversal, across Python, C99, JS/TS, Java and ESP32.

  • 20% loss without stalling
  • ~65 KB on ESP32
Details GitHub PyPI v1.3.2
Central complex

NeckCompass neckcompass

A 16-wedge E-PG ring-attractor compass and CPU4 GPS-denied path integrator. It rejects 70°–150° magnetic spikes as well as a gated EKF, and re-anchors after heading upsets where the EKF stays stuck, in 324 bytes of C99 RAM.

  • 0.44° RMSE under spikes
  • ~1 µs per step (desktop)
Details GitHub PyPI v1.1.0
Optic lobe

NeckSight necksight

R1–R6 glare adaptation, T4/T5 motion detectors and an LPLC2 four-quadrant looming E-stop (0.9988 AUROC on synthetic clutter), with gyro derotation so obstacles are still caught during fast turns.

  • ~12,000 FPS in C99 (desktop)
  • 14.27 KB at 32×32
Details GitHub PyPI v1.1.0
Ventral nerve cord

NeckCord neckcord

A 4-byte descending motor command frame (400 B/s at 100 Hz), a self-healing six-limb hexapod CPG and a fault-tolerant thruster allocator that isolates failed thrusters and can return them to service.

  • 42 ms fault isolation
  • 322 B of C99 state
Details GitHub PyPI v1.1.0
Antennal lobe & mushroom body

NeckSense necksense

Olsen-Wilson concentration-invariant normalisation feeding a multiplication-free winner-take-all FlyHash, for one-shot classification and one-shot anomaly detection on integer-only MCUs.

  • 0.994 anomaly AUROC (4 KB)
  • Bit-identical Python ↔ C99
Details GitHub Install
