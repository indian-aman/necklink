Tiny brains.
Compiled from a real fly.

Five open-source libraries that run weight matrices compiled from the 157,789-neuron adult Drosophila BANC v888 connectome inside hand-designed dynamics — including a 4-organ reflex controller plus MAVLink v2 in 24 KB of zero-float, zero-heap ANSI C99 RAM — plus the NLTP wire protocol. Research beta: tested against shuffled wiring in simulation, not yet on real hardware.

Modules

Five standalone organs + one unified Whole-CNS copilot.

Install any individual organ on its own, or the unified 24 KB NeckLinkCNS reflex controller with MAVLink v2 and ROS 2 bridges. Every connectome-driven class also offers connectome_weights="v2_analytic", the earlier hand-tuned model.

Cervical connective · v1.6.0

NLTP pynltp

Loss-resilient UDP & ESP-NOW file, telemetry and reflex transport with GF(2^8) Cauchy FEC, per-session ChaCha20-Poly1305 AEAD, and single-port 4G CGNAT traversal across Python, C99, JS/TS, Java and ESP32.

  • 35% loss 100% SHA-256
  • ~65 KB on ESP32

Central complex · v3.0.0

NeckCompass neckcompass

9-axis ring-attractor heading and PFL3/PFL2 GPS-denied homing on EPG/PEN/Delta7 matrices compiled from the connectome. Shuffled wiring breaks it; the real wiring drifts and is less accurate than the analytic model or an EKF.

  • 100% vs 4.7% homing (real vs shuffled)
  • ~3,900 connectome weights
Details GitHub v3.0.0
Optic lobe · v3.0.0

NeckSight necksight

Collision and thin-obstacle reflex with 3-DOF gyro derotation; 64 LPLC2 and 32 LC4 receptive fields compiled from the connectome. LC4 is what catches thin poles and wires.

  • 0.755 thin-obstacle AUROC
  • 14.3 KB C99 state
Details GitHub v3.0.0
Ventral nerve cord · v3.0.0

NeckCord neckcord

Six-leg gait whose tripod pattern emerges from a 6×6 VNC inhibition matrix compiled from the connectome, plus engineering layers: rotor/thruster allocator, sensorless ESC observer and 18-servo IK.

  • 0.855 vs 0.411 tripod order
  • 930 B total C99 SRAM
Details GitHub v3.0.0
Mushroom body & chordotonal · v3.0.0

NeckSense necksense

Integer mushroom body with real Kenyon-cell claws (1,024 cells), novelty detection, 2-compartment continual memory and a 16-band vibration front-end. Shuffled wiring performs the same; classical methods win on real gas data.

  • 5.8 KB tiny build
  • = shuffled wiring (honest null)
Details GitHub v3.0.0
Unified Whole-CNS · v3.0.0

NeckLink CNS necklink-cns

Combines the four organs through a decision layer that is matrix multiplication through connectome weights (brain populations → DNp01 / MDN / DNa02 → leg pools), plus MAVLink v2 and ROS 2, in 24,024 B of C99 RAM.

  • 66.7% vs 4.6% sim mission (real vs shuffled)
  • 107.5 KB standalone WASM

Architecture

Compiled from the BANC v888 adult Drosophila CNS

In v3.0.0 each module's core circuit runs on weight matrices compiled from the connectome (about 33,000 numbers in total), inside hand-designed dynamics. Scrambling the wiring breaks the compass, homing, gait and whole controller, but not the mushroom body — and the hand-tuned analytic model is still more accurate everywhere.
